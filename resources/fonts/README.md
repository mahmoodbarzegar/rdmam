# Font Requirements for Ravand Website

This website requires the following fonts for proper display according to the Figma design:

## Required Fonts
1. **Dast Nevis** - Used for hero section headings
2. **Yekan Bakh FaNum** - Used for body text and other content

## Font Files
The following files should be in this directory:
- DastNevis.woff
- DastNevis.woff2
- YekanBakhFaNum-Regular.woff
- YekanBakhFaNum-Regular.woff2
- YekanBakhFaNum-Bold.woff
- YekanBakhFaNum-Bold.woff2
- YekanBakhFaNum-Light.woff
- YekanBakhFaNum-Light.woff2
- YekanBakhFaNum-SemiBold.woff
- YekanBakhFaNum-SemiBold.woff2

## Notes
- The font files should be properly named as above to match the CSS references
- Currently, there might be naming inconsistencies in some files (e.g., "Danstevis" instead of "DastNevis")
- Make sure all font formats (woff and woff2) are available for maximum browser compatibility
